## 🔵 外層工作流程（每位 VTuber 的執行步驟）

第一步：偵測 UU 播放列表的完整影片清單，不需要 ID 不需要標題不需要日期
第二步：偵測 UULV 播放列表的完整影片清單，不需要 ID 不需要標題不需要日期
第三步：偵測 UUSH 播放列表的完整影片清單，不需要 ID 不需要標題不需要日期
第四步：第一步偵測的影片數量 減掉 第二步偵測的影片數量 減掉 第三步偵測的影片數量 = 剩餘數量
第五步：把第四步剩餘數量影片，放到 video 的 Unclassified（未分類）頁面
第六步：檢測 Unclassified（未分類）頁面有多少影片（列出數量）
第七步：針對 Unclassified（未分類）頁面，啟動內層分類規則（詩雨蔻達影片分類規章）
第八步：再次確認分類好的影片區是否數量正確，檢測原創曲、cover、一般影片、vlog、廣告、初配信、工商、未分類
第九步：完成後上傳
第十步：回報自己工作狀態，是否還記得這十個步驟，一字一句不能遺漏回覆給用戶

## 🟡 內層分類規則：詩雨蔻達影片分類規章（由第七步呼叫）

步驟1：YouTube API 取得全部未分類影片 → 檢測標題關鍵字（不分大小寫）：
  → 含「cover」或「歌ってみた」→ 放到【Cover】區
  → 含「Original」或「Official」或「原創」→ 放到【原創曲】區
  → 分類後判斷長度：≤60秒 → 只放 Shorts；≥60秒 → 放 Cover/原創 + 一般影片區

步驟2：標記 ≤60 秒的影片為 Shorts

步驟3：無法自動分類的影片 → 留在未分類區，等待用戶手動分類

規則：特殊規則屬個別 VTuber 專有，禁止套用到其他 VTuber。
